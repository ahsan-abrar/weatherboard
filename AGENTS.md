# Agent Rules

## Prompt Logging
- **Always log every user prompt** into `PROMPTS.md` located at the root of the project upon receiving each request.
- Keep entries formatted in chronological order with timestamps and the exact prompt text.

## UI
- Use **lucide-react** for all interface icons.

## Code Comments
- Add **short, plain-English comments** wherever logic, data flow or a browser/API quirk is not obvious.
- Comment **why** something is done, not what the syntax already says.
- Keep comments accurate: update them in the same change as the code.
- Avoid commented-out code and line-by-line narration.
